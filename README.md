# ai-edge-reu-ml-experiments
CNN, Vision Transformer, and VAE experiments on Fashion-MNIST and MNIST (AI-EDGE REU, Summer 2026).

- **CNN notebook:** data loading is from a program-provided starter; the model variants, experiment loop, and analysis are my work.
- **ViT notebook:** uses the ViT implementation from [ml-tutorials-suite](https://github.com/williamqwu/ml-tutorials-suite). My work was adapting it to Fashion-MNIST (input size, channels), training with AdamW, and comparing against the CNN.
